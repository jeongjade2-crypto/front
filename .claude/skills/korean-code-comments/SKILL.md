# 한글 주석 규칙

이 프로젝트에서는 새로 쓰거나 고치는 모든 코드에 상세한 한글 주석을 단다. **주석이 빠진 코드는 미완성으로 간주**하며, 아래 세 가지가 모두 채워지기 전까지는 그 파일 작업을 끝낸 것으로 보고하지 않는다.

## 지켜야 할 것

1. **파일 맨 위**: 파일 최상단에, 이 파일이 무슨 일을 하는지 2~3줄로 설명하는 주석을 단다.
2. **함수 위**: 모든 함수(리액트 컴포넌트 포함) 바로 위에, 무엇을 입력으로 받아서 무엇을 돌려주는지 설명하는 주석을 단다.
3. **복잡한 부분**: 로직이 복잡하거나 왜 이렇게 했는지 코드만 봐서는 알기 어려운 부분에는, 그렇게 구현한 이유를 설명하는 주석을 단다.

## 적용 범위

- 새로 작성하는 코드와 기존 코드를 수정하는 경우 모두 적용한다.
- 한 파일을 여러 번 나눠 수정하더라도, 수정이 끝난 시점에는 위 세 가지가 전부 채워져 있어야 한다.
- 이미 있는 주석이 최신 코드와 어긋나면(설명이 틀렸으면) 코드에 맞게 고친다.

## 점검

코드 작업을 마쳤다고 보고하기 전에, 방금 만들거나 고친 파일에 대해 스스로 다음을 확인한다.
- [ ] 파일 맨 위에 2~3줄 설명이 있는가
- [ ] 모든 함수 위에 입력/출력 설명이 있는가
- [ ] 복잡한 부분에 '왜'를 설명하는 주석이 있는가

하나라도 빠졌다면 주석을 채운 뒤에 작업 완료로 보고한다.
